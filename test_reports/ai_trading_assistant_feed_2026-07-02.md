# AI Trading Assistant — Bot Decision Feed Redesign

Date: 2026-07-02

## What changed

The Bot Decision Feed is redesigned from a raw event-log viewer into a
conversational "watching the AI think" experience, and moved from the Home
page / Activity tab into the **Trading** page, per explicit request.

No EA changes were needed. Research confirmed the EA and backend already
send near-natural-language fields (`reason`, `decision`, `grade`,
`market_bias`, `ai_confidence`, and — when the AI Director was consulted —
`thesis`) alongside the raw telemetry. The redesign is a translation layer
over data that already exists, not a new data pipeline.

## Architecture decision: templates, not a live LLM call

Per explicit choice: narration is composed from existing structured fields
via a phrase-bank, not generated by a live LLM call on every tick. This
keeps it free and instant — no added AI spend or latency on top of what the
bot already pays for trade-decision AI calls — while still reading as
natural, varied English rather than a robotic dump.

## Backend (`backend/server.py`)

New "AI Thought Engine" section (~200 lines): `_ai_bias_word`,
`_ai_split_reason_clauses`, `_ai_classify_card_type`,
`_ai_build_thought_card`, `_ai_would_enter_again` — pure functions with no
side effects, translating a raw `cloud_bot_activity` document into a
"thought card": headline, bias, confidence (+ delta from the prior card for
the same ticket), decision text, reason bullets, tone, and a `advanced`
sub-object carrying the raw telemetry for the Developer Details view.

Two new endpoints:
- `GET /cloud/monitor/decision-feed` — thought cards + a derived timeline,
  same auth/license-scoping pattern as the existing activity feed.
- `GET /cloud/monitor/current-opinion` — the Current Trade panel: live
  bias/confidence, entry reason, and a heuristic "would I enter this trade
  again right now" verdict. Hold/exit/reversal probabilities are explicitly
  documented in code as confidence-derived estimates, not literal ML
  outputs — this repo doesn't have a separate probability model, and
  presenting the numbers without that caveat would overclaim precision.

## Frontend

New `frontend/src/components/cloud/AIThoughtFeed.jsx`:
- `ThoughtCard` — the conversational card (Market Analysis / Trade Executed
  / Live Thoughts / Warning / Trade Closed / Trade Blocked), each with a
  Simple/Advanced toggle and a collapsed "Developer Details" dropdown
  showing the raw JSON telemetry. No raw variable names or ATR-style dumps
  appear anywhere outside that dropdown.
- `DecisionTimeline` — vertical timeline derived from the same feed.
- `CurrentTradePanel` — bias/confidence/hold/exit probabilities plus the
  YES/NO "would enter again" verdict with a reason when NO.
- `compact` mode — a single-card teaser used on the Home page (replacing
  the old raw "Bot Decision Feed" card there) that links into the full
  experience on Trading.

`CloudDashboard.jsx`: `TradingPage` now renders `<AIThoughtFeed>` instead
of the raw `DecisionSummaryCard`/`DecisionHistory`/event-list stack.
`HomePage`'s old "Bot Decision Feed" card is replaced with the compact
teaser. The Activity tab is untouched — it keeps the raw technical log for
anyone who explicitly navigates there; it's no longer the home of the AI
narrative.

## Testing

`tests/test_ai_thought_engine_narrative.py` — 10 functional tests (not
just static string matching) exercising the actual narrative functions
with realistic mock events: bias mapping, reason-clause splitting/dedup,
card-type classification, confidence-delta computation, tone escalation,
and the "would enter again" verdict.

Also did a real end-to-end smoke test: installed the backend's runtime
deps into a scratch venv, ran the server against a local MongoDB, inserted
a realistic 7-event trade lifecycle (market analysis → entry → two live
thoughts → warning → close, plus a blocked-trade example), and called both
new endpoints directly. This caught two real bugs before shipping that the
unit tests alone missed because they used more forgiving mock data:

1. **Market Analysis card showed raw internal message text** ("AI Director
   verdict") instead of "Preparing BUY" whenever the EA's `message` field
   was non-empty — the fallback chain preferred raw text over the composed
   bias-based phrase the design calls for. Fixed: the decision line for
   this card type is now always composed from `bias`, never falls back to
   raw message text.
2. **Trade Executed card showed "Entry allowed"** (the engine's internal
   decision label) instead of "BUY executed" for the same reason. Fixed.

Also tuned the Warning-vs-calm threshold using the user's own mockup
numbers as the spec: a 93%→81% pullback should stay "Live Thoughts" (calm),
while 81%→63% should escalate to "Warning". The original thresholds
(confidence < 70, or any drop ≥ 10 points) would have wrongly flagged the
first case; raised to confidence < 65 and drop ≥ 20 points, verified against
both cases with a unit test.

Full suite: 159/159 passed (149 previous + 10 new).
