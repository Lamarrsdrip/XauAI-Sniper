# Old versus new normal-entry decision path

## Old v6.23.3 path

Candidate → grade → Active Direction → personality penalty/recheck → SMC penalty/hard skip → TRI → FIX-C demotion → post-news duplicate approval → STI late/exhaustion branches → basket-loss fear → direction loss lock → recovery gate → Hive → AI skip/missing/confidence sizing → adaptive drawdown → TradeBrain/memory sizing → full-risk quality block → old-direction exhaustion → elapsed timing state → recovery mailbox/timer → GrowthGuard/final adaptive recheck inside `OpenTrade` → broker.

Several modules could block the same fact, a warning could become hard later, and an early rejected idea could be stored and reopened after price had already moved.

## New v6.24.0 path

Candidate and grade → confirmed opposite structure check → live freshness/extension check → single 120–180 second delay → live freshness recheck at release → protected-news check → re-entry/pyramid state where applicable → configured operational risk → final convergence record → `OpenTrade` operational checks → broker.

The timing correction preserves the requested 2–3 minute delay without restoring the old gauntlet. The first scan arms one lane clock. When it matures, the scan runs promptly rather than waiting for the next M5 bar. If price has already consumed the move and remaining reward has collapsed, freshness rejects it; it cannot become an approve-late recovery.
